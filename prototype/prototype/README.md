# EOS Prototype v0.1

**Conceptual Architecture: Lucian Yaqín Varela**
**June 2026**

---

## What This Is

This is the first running prototype of the EOS core engine.

It is not the full system.
It is not connected to an LLM yet.
It is the skeleton — the state engine, coherence tracker,
sovereign memory governance, and agent system running
as a standalone Python script.

It proves the architecture is operational.

---

## What It Demonstrates

- Nine emotional operating states with governance validation
- Three coherence vectors (IC / RC / NC) with live tracking
- Sovereign Memory Governance — importance scoring and pruning
- Four-agent status system (Weaver, Archivist, Caretaker, Sentinel)
- Meta-Observer layer — second order system analysis
- Persistent memory across sessions via local JSON

---

## How To Run It

Requires Python 3.8 or higher. No external libraries needed.

```bash
python eos_core.py
```

---

## Commands

| Command | What It Does |
|--------|--------------|
| `state <StateName>` | Transition to a new emotional state |
| `memory <text>` | Store an experience in memory lineage |
| `recall` | View top importance memories |
| `agents` | View current agent statuses |
| `cohere <IC> <RC> <NC>` | Apply coherence vector deltas |
| `observe` | Run meta-observer analysis |
| `status` | Show current system status |
| `exit` | Shutdown and persist memory |
